# Questions fréquentes

**Faut-il saisir chaque compte tous les mois ?**
Non : un compte sans relevé garde son dernier solde connu (reporté). Saisissez ce qui bouge.

**Comment saisir un crédit ?**
Comme un compte de nature passif, avec le capital restant dû en positif : Patrimeter le soustrait.

**J'ai oublié mon mot de passe.**
Lien « Mot de passe oublié ? » ; avec votre clé de récupération, vous gardez vos données
([sécurité](securite.md#mot-de-passe-oublie)).

**J'ai perdu mon téléphone.**
Connectez-vous avec un code de secours, puis changez d'application dans Mon compte.

**L'administrateur peut-il voir mes montants ?**
Non : ils sont chiffrés avec une clé que seul votre mot de passe (ou votre clé de récupération) ouvre. Il
voit en revanche votre adresse, le nombre de vos comptes et les mois saisis, et le journal des connexions
([sécurité de l'application](../SECURITY.md)).

**Puis-je changer de serveur ?**
Oui : [exportez vos données](donnees.md), puis importez-les sur la nouvelle instance.

**Le site est-il utilisable sans JavaScript ?**
Oui : chaque écran fonctionne sans JavaScript, qui n'ajoute que du confort (graphique, calendriers des mois, listes de
types à saisie).

**Quelle version de Patrimeter est installée ?**
Elle est affichée en bas de chaque page, page de connexion comprise (« Patrimeter, version X.Y.Z »).

**J'ai commencé Patrimeter en novembre : comment saisir les mois d'avant ?**
Allez sur le mois voulu, puis **Copier les soldes d'un autre mois** depuis novembre : les comptes ouverts depuis sont
repris, et la validation avance leur date d'ouverture ([saisie du mois](saisie.md#copier-les-soldes-dun-autre-mois)).

**Après une mise à jour, l'écran n'a pas changé.**
Rechargez la page en forçant le cache du navigateur (Ctrl+Maj+R). Si rien ne change, l'administrateur vérifie
la mise à jour du serveur ([vérifier la mise à jour](../exploitation/mise-a-jour.md#2-sur-linux)).

**Comment passer en anglais ?**
Cliquez sur le bouton de langue (globe et **FR**), à côté de celui du thème, puis sur **English** ; même chemin
pour revenir au **Français**. Le choix est retenu sur l'appareil.

**Pourquoi le menu « Saisie du mois » est-il en gras, avec un point rouge ?**
Aucun solde du mois en cours n'est encore saisi : il vous le rappelle, et redevient normal dès la saisie. Un rappel
par e-mail est aussi possible ([Mon compte, rappel mensuel](securite.md#rappel-mensuel)).

**Où sont mes objectifs d'épargne ?**
Menu **Objectifs** pour les suivre ; **Saisie du mois**, onglet **Objectifs**, pour les créer et les modifier
([objectifs d'épargne](objectifs.md)).

**Puis-je essayer Patrimeter sans créer de compte ?**
Oui, si l'instance propose la démonstration : **Essayer la démo** sur la page de connexion. Le compte et ses données
fictives sont supprimés au bout de 2 heures ou à la déconnexion ([essayer sans compte](premiere-connexion.md#essayer-sans-compte)).
